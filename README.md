# Portfolio — Camille Rousseau

Site vitrine pour photographe portraitiste (personnage fictif), conçu et développé dans le cadre d'un portfolio personnel.

## Démarche

Site éditorial à la croisée du magazine et du portfolio d'auteur. Mise en avant du travail photographique via une grille asymétrique inspirée des mises en page presse.

## Technologies

- HTML5 sémantique
- CSS3 (Grid, Flexbox, animations, filtres)
- Responsive design (mobile-first)
- Typographie Google Fonts (Fraunces, Inter)

## Points techniques

- Grille de galerie asymétrique avec hauteurs harmonisées par rangée
- Animations d'entrée séquencées (fadeUp avec délais)
- Hover states travaillés (zoom + désaturation des images)
- Formulaire de contact stylé

## Crédits

Personnage et projet fictifs. Photos issues d'[Unsplash](https://unsplash.com) (libres de droits).
